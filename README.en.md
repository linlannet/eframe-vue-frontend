- [Vite](https://vitejs.dev/) - Familiar with vite features

## Install and use

- Get the project code

```bash
git clone https://gitee.com/linlannet/eframe-vue-frontend.git
```

- Install dependencies

```bash
cd eframe-vue-frontend

npm install

```

- run

```bash
npm serve
```

- build

```bash
npm build
```
